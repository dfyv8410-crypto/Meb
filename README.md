# MEB — Premium Furniture CMS
Премиальная CMS для мебельного производства: сайт + админка + API + установщик.

## Запуск (shared hosting)
```
# Загрузите файлы на хостинг (Sweb.ru, etc.)
# Откройте https://ваш-домен/installer/ — мастер установки
# Войдите в /admin
```

## Локальная разработка (localhost)
Нужны: **PHP >= 7.2 (CLI)** и установленный **MySQL/MariaDB**.

```
scripts/start-dev.sh              # поднимет БД (если не запущена) + php -S на 127.0.0.1:8099
```
После строки `Server ready` открой http://127.0.0.1:8099/ — сайт, админка на `/admin`,
API на `/api/v1`. Если чего-то не хватает: конфиг `config/` генерируется мастером
`http://127.0.0.1:8099/installer/` (БД нужно создать заранее, см. `sql/schema.sql`).

Другие адреса:
```
HOST=0.0.0.0 PORT=8099 scripts/start-dev.sh   # доступ с других устройств (http://<IP>:8099)
```
Стоп: `kill $(cat /tmp/meb-php-serve.pid)`.
**Важно:** `php -S` запускается только через `scripts/dev-router.php` (маршрутизация как в
`.htaccess`). Простой `php -S localhost:8099` без роутера сломает админку/API — это не баг.

## Структура
- `api/v1/` — REST API (36+ эндпоинтов)
- `admin/` — SPA без сборки (14 разделов)
- `pages/` — публичные страницы (SSR, PHP)
- `installer/` — веб-установщик (7 шагов)
- `includes/` — ядро (auth, database, helpers, security)
- `config/` — конфигурация (создаётся установщиком)
- `storage/` — данные, загрузки, бэкапы
- `public/` — CSS, JS, изображения
- `scripts/` — тесты и утилиты
- `sql/` — схема базы данных
