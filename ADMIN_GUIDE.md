# ADMIN GUIDE — Руководство администратора

Вход: `/admin`. Боковое меню, всё в 2–3 клика.

## Dashboard
Счётчики (заявки, проекты, каталог), статус системы, быстрые действия.

## Страницы (Page Builder)
Конструктор: 9 типов блоков (hero, text, features, gallery, statistics, faq, cta, team, contact).
Страница доступна на `/p/<slug>`. Скрытие блока: `hidden: true`.

## Каталог / Проекты / Материалы / Услуги
Добавить → title + slug + описание + изображения. Опубликовать/скрыть одним кликом.

## Заявки (CRM)
Публичная форма → автоматически сюда. Статусы: new → in_progress → contacted → done / rejected.
Статус меняется выпадающим списком прямо в таблице.

## Отзывы
Модерация: одобрен / отклонён. Новые отзывы появляются после проверки.

## Меню
Динамическое меню навигации: добавление, сортировка, включение/выключение пунктов.

## Медиа
Загрузка файлов + ALT (для SEO). Копирование URL, удаление. Папки.

## Пользователи
Роли: super_admin > admin > manager > editor. Последнего админа удалить нельзя.

## SEO
Аудит сайта: проверка slug, description, изображений. Генерация sitemap.xml.

## Настройки
- Сайт: название, телефон, email, адрес, логотип, фавикон
- SEO: title, description, keywords, OG (title, description, image)
- Соцсети: Instagram, Telegram, WhatsApp, VK, YouTube
- Уведомления: email для уведомлений о заявках
- Часы работы, копирайт

## Система
- System Health: проверка DB, storage, API
- Оптимизация БД, очистка кэша
- Бэкапы: создание, список, восстановление (с pre-restore snapshot)

## Уведомления
Колокольчик в шапке: непрочитанные заявки, отзывы.
