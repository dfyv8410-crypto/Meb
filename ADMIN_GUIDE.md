# ADMIN GUIDE — Руководство администратора

Вход: `/admin`. Боковое меню, всё в 2–3 клика.

## Dashboard
Счётчики (заявки, проекты, каталог), статус системы, быстрые действия.

## Страницы (Page Builder)
Конструктор: 9 типов блоков (hero, text, features, gallery, statistics, faq, cta, team, contact).
Страница доступна на `/p/<slug>`. Скрытие блока: `hidden: true`.

## Каталог / Проекты / Материалы / Услуги
Добавить → title + slug + описание + изображения. Опубликовать/скрыть одним кликом.
В форме товара категория выбирается из выпадающего списка (раздел «Категории»).

## Категории (каталог)
Меню → Каталог → Категории. Список: название, родитель, slug, число товаров, порядок, статус.
Поля категории:
- Название — обязательно.
- Slug — адрес страницы `/catalog/<slug>`; если пусто, генерируется из названия (кириллица → латиница).
- Родительская категория — создаёт вложенность (разделённые подкатегории на публичном сайте).
- Описание, Обложка (медиа-пикер), Порядок сортировки (меньше = выше), Статус (Активна = публикуется).
Скрытая категория не показывается на сайте: ни в каталоге, ни в меню, ни в sitemap (страница → 404).
Удаление безопасно: подкатегории и товары переезжают в родительскую категорию; если у удаляемой
категории нет родителя, а товары есть — удаление заблокируется, пока товары не перенесут.

## Заявки (CRM)
Публичная форма → автоматически сюда. Статусы: new → in_progress → contacted → done / rejected.
Статус меняется выпадающим списком прямо в таблице.

## Отзывы
Модерация: одобрен / отклонён. Новые отзывы появляются после проверки.

## Меню
Динамическое меню навигации: добавление, сортировка, включение/выключение пунктов.

## Медиа
Загрузка файлов + ALT (для SEO). Копирование URL, удаление. Папки.

## Пользователи
Роли: super_admin > admin > manager > editor. Последнего админа удалить нельзя.

## SEO
Аудит сайта: проверка slug, description, изображений. Генерация sitemap.xml.

## Настройки
- Сайт: название, телефон, email, адрес, логотип, фавикон
- SEO: title, description, keywords, OG (title, description, image)
- Соцсети: Instagram, Telegram, WhatsApp, VK, YouTube
- Уведомления: email для уведомлений о заявках
- Часы работы, копирайт

## Настройки → Защита фото (watermark)
Раздел в «Настройки». Логотип автоматически наносится на все изображения сайта
(Mobile/Tablet/Desktop/Retina — на каждую сгенерированную WebP-версию). Оригиналы не изменяются.
- **Включить защиту фото** — глобальный переключатель.
- **Логотип** — PNG с прозрачным фоном (уже загружен логотип «ГОДНАЯ МЕБЕЛЬ»). Можно заменить.
- **Непрозрачность** 0–100% (по умолчанию 25) — насколько виден знак.
- **Размер** 4–45% от меньшей стороны изображения (по умолчанию 22).
- **Расположение** — 9 позиций (по умолчанию нижний правый).
- **Режим**: «Одиночный» (один знак в углу) или «Повторяющийся» (сетка по всему фото).
- **Предпросмотр** — живая картинка на реальном фото при каждом изменении.
После «Сохранить всё» старые версии изображений больше не запрашиваются (кэш инвалидируется
автоматически); старые файлы можно подчистить «Очистка кэша» в System.

## Система
- System Health: проверка DB, storage, API
- Оптимизация БД, очистка кэша
- Бэкапы: создание, список, восстановление (с pre-restore snapshot)

## Уведомления
Колокольчик в шапке: непрочитанные заявки, отзывы.
